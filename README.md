# real-car-driving-experience

A browser-based **Real Car Driving Experience** prototype focused on realistic-feel practice driving in a city layout.

## Features

- Real-time steering, acceleration, braking, and handbrake controls
- Car type selector (Hatchback, Sedan, SUV, Sport, Supercar) with different handling/speed
- Camera options: Follow, Driver, Overhead
- Day/Night mode toggle for visual driving conditions
- AI traffic moving through a city intersection
- Traffic signal system (EW/NS light cycle)
- Direction/checkpoint objective with distance feedback
- Parking mode with marked parking bay and completion check
- Responsive UI with keyboard-accessible controls and status announcements

## Run

```bash
npm start
```

Then open `http://localhost:4173`.
